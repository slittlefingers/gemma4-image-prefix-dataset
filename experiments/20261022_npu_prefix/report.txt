All prefix models selected step 0: the ridge initializer. Attention training did not improve held-out validation.

Final trained checkpoints retained as prefix_last.pt; best-validation checkpoint is prefix_model.pt.

Limitations:
8 held-out images in one test sequence; positions are correlated.
Embedding errors only. No phone attached; no NPU re-forward KV error measured.
Training uses exact prefixes. Rollout substitutes all previous image predictions from position 5.
Known template/separator embeddings and their positions retained in rollout.
Raw quantized K/V and absolute position are inputs; no guessed inverse RoPE.
No original image reconstruction training; archive contains embeddings and KV, not JPEGs.
Dataset fixed-prefill protocol differs measurably from single-position query path.

Run from the repository root:
python experiments/20261022_npu_prefix/train.py --steps 2000 --seed 20261022 --out experiments/20261022_npu_prefix/results_seed20261022
python experiments/20261022_npu_prefix/infer.py --checkpoint <prefix_model.pt> --input <input.npz> --output <embedding.npy>
Input NPZ: prefix float32 array [p,1536], kv raw int8 array [1024].
Original 60-token synthetic-image decoder is not applied to these variable 256-280-token natural images.
